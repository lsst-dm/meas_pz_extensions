######################
meas_photoz_algorithms
######################

``meas_photoz_algorithms`` is an extension to the `meas_photoz_base <https://github.com/lsst-dm/meas_photoz_base>`_package from the `LSST Science Pipelines <https://pipelines.lsst.io>`_.

meas_photoz_algorithms contains classes and tasks for running additional photometric redshift algorithms not provided in `lsst_distrib`.

meas_photoz_algorithms relies on the DESC `Redshift Assessment Infrastructure Layers (RAIL) <https://github.com/LSSTDESC/rail/>`_ framework.
Users must install the requisite RAIL packages via conda or pip to be able to run each algorithm.
