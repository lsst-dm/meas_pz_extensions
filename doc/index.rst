###########################
lsst.meas.photoz.algorithms
###########################

meas_photoz_algorithms contains additional photometric redshift algorithms not provided in the lsst_distrib environment and thereby not available in `meas_photoz_base <https://github.com/lsst/meas_photoz_base>`_.

.. .. _lsst.meas.photoz.algorithms-using:

Using lsst.meas.photoz.algorithms
=================================

Consult the unit tests and/or the pipelines in `drp_pipe <https://github.com/lsst/drp_pipe>`_ for suggested usage.

To populate the `photozAlgoRegistry`, import from `lsst.meas.photoz.algorithms.all_algos`.
